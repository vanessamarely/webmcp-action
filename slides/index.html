Loop de tool calls

mcp-client/src/llm/claude.ts
for (let i = 0; i < MAX_STEPS; i++) {
  const res = await client.messages.create({
    model, tools, history,
  });

  const calls = res.content
    .filter(b => b.type === "tool_use");

  if (!calls.length) return res.text;
  for (const c of calls) await runTool(c.name, c.input);
}

No compiten. Se complementan.

En el navegador — WebMCP. Configurar un producto, navegar el catálogo, llenar el carrito — tools que comparten la UI y el estado que el usuario está viendo.

En un servidor — MCP. Confirmar el pedido, verificar stock o cobrar — tools conectadas a servicios y reglas de negocio en un proceso local o remoto.

Antes de ejecutar: confirmar

Una tool puede preparar una acción sin autorización para completarla. El último paso debe devolver el control al usuario.

// 01 · PREPARAR
Validar intención
Revisar parámetros, permisos y alcance. Todavía no cobrar ni borrar.
// 02 · CONFIRMAR
Pedir aprobación explícita
Mostrar qué ocurrirá y esperar un gesto del usuario: confirm().
// 03 · EJECUTAR
Resolver la tool
Solo después de la aprobación se crea el pedido, se cobra o se elimina.
>  reversible = automático · irreversible = human_in_the_loop
